// ==========================================
// 1. ALUR GUEST MODE (PENGAJUAN MITRA)
// ==========================================
Mulai > Isi Form Pengajuan (Guest Mode)
Isi Form Pengajuan (Guest Mode) --> DKUI Cek Form Pengajuan
DKUI Cek Form Pengajuan > Form Lolos?

// Jika DKUI Menolak Form Awal
Form Lolos? --> DKUI Kirim Email Penolakan : Tidak [color: red]
DKUI Kirim Email Penolakan > Terima Email Penolakan
Terima Email Penolakan > Selesai_Ditolak

// Jika DKUI Menerima Form Awal
Form Lolos? > DKUI Salurkan ke Unit Terkait : Ya
DKUI Salurkan ke Unit Terkait > Review Awal Kesediaan Unit
Review Awal Kesediaan Unit > Unit Bersedia?

// Jika Unit Menolak Tawaran
Unit Bersedia? --> DKUI Kirim Email Penolakan : Tidak [color: red]

// Jika Unit Menerima (Penetapan Inisiator & Penandatangan)
Unit Bersedia? > DKUI Tetapkan Inisiator & Assign Pimpinan Unit : Ya
DKUI Tetapkan Inisiator & Assign Pimpinan Unit > Sistem Kirim Akun ke Mitra
Sistem Kirim Akun ke Mitra > Penjajakan Kerja Sama_Mitra

// ==========================================
// 2. ALUR PENJAJAKAN & DRAFTING
// ==========================================
Penjajakan Kerja Sama_Mitra <--> Penjajakan Kerja Sama_Internal : Proses Penjajakan [cite: 196]
Penjajakan Kerja Sama_Internal > Susun Draf Awal [cite: 236]
Susun Draf Awal > Ajukan Draf ke Sistem [cite: 138]
Ajukan Draf ke Sistem --> DKUI Menerima Draf

// ==========================================
// 3. ALUR REVIEW BERJENJANG
// ==========================================
DKUI Menerima Draf > Review & Analisis oleh Pimpinan Unit
Review & Analisis oleh Pimpinan Unit > Setuju?_Unit

Setuju?_Unit > Verifikasi oleh Pimpinan DKUI : Ya
Setuju?_Unit --> Eksekusi Perbaikan : Tidak [color: red]

Verifikasi oleh Pimpinan DKUI > Setuju?_DKUI
Setuju?_DKUI > Review Hukum : Ya 
Setuju?_DKUI --> Eksekusi Perbaikan : Tidak [color: red]

Review Hukum > Setuju?_Hukum
Setuju?_Hukum --> Eksekusi Perbaikan : Tidak [color: red]

// ==========================================
// 4. LOGIKA REVISI (LOOP)
// ==========================================
Eksekusi Perbaikan > Persetujuan Ulang Substansi [cite: 243]
Persetujuan Ulang Substansi --> Review & Analisis oleh Pimpinan Unit : Draf Diperbaiki

// ==========================================
// 5. RANTAI PENGESAHAN (PIMPINAN UNIT)
// ==========================================
// Langsung ke TTE Pimpinan Unit tanpa melalui Sekretaris Universitas atau Rektor
Setuju?_Hukum > TTE Pimpinan Unit : Ya 

TTE Pimpinan Unit --> Tanda Tangan Naskah : Naskah Disahkan
Tanda Tangan Naskah --> Pengarsipan : Penyerahan Naskah [cite: 141]
Pengarsipan > Selesai_Berhasil
